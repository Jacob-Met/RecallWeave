# Sorting-network lesson and offline lab delivery

The learner can enter a fixed comparator sequence, follow every comparison and unchanged step, and test every binary input for that exact network. The twelve-question lesson can be imported into the unchanged RecallWeave learner and continued through review, missed-question practice and a real study-notes download.

## Open and use

Download `courses/dist/sorting-networks-offline.zip` from this exact source tree and extract all six regular members together. Open `courses/sorting-networks-explorer.html` directly in a browser. No server, package installation or network is required. The ZIP is 49,582 bytes, SHA256 `1de74462a7c755b51d6a43ccf75cee492755510eac22c1274341bdae98328c5f`, Git blob `ddcf36df7bbd8692240c569e322126e025464fda`.

1. Choose an example, then press **Use as draft**. Browsing the chooser alone does not replace the draft or accepted result.
2. Edit the wire count, values and ordered comparator pairs, then press **Run**. Every actual draft edit immediately retires the old result and its result downloads.
3. Follow the complete trace or select an exhaustive binary case. The incomplete four-wire example exposes concrete failing inputs. Selection changes the view, not the accepted configuration.
4. Download the configuration, complete observation or fixed lesson JSON. Open the packaged `demo.html` learner using the lab link, select the actual lesson file, review its preview and explicitly start it.
5. Answer the twelve questions, review, practice a missed question and save study notes. First answers remain separate from later practice.

The guide is [courses/sorting-networks.md](../../../courses/sorting-networks.md). The public limits are 2–6 wires, 0–30 ordered comparator pairs, exactly one integer value per wire in [-999,999], and explicit 1-based pairs with lower index first. The exhaustive result covers all 2^n binary inputs for that fixed sequence. It does not claim minimum size, hardware speed, parallel depth, stable record sorting or measured learning efficacy.
