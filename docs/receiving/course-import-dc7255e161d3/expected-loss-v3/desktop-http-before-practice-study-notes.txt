First try: correct
Correct answer: Rework when p>0.10, Release when p<0.10, and either at p=0.10.
Explanation: Release has expected loss 18p. Rework has 2(1-p). Rework is better exactly when 2(1-p) < 18p, or 2 < 20p, hence p > 0.10. Below 0.10 choose Release; at 0.10 both minimize expected loss. The threshold comes from the loss table, not a universal 0.50 rule. At p=0 and p=1 the rule also gives the respective zero-loss action.

6. A and B are the only available actions. Their losses in [good,flawed] order are A=[1,4] and B=[2,5]. The flawed probability p is unknown but lies in [0,1]. What follows without assigning any distribution to p?
Concept: decision-limits
Your first answer: A has exactly one point less expected loss than B for every p.
First try: correct
Correct answer: A has exactly one point less expected loss than B for every p.
Explanation: For any p, A has (1-p)×1 + p×4 = 1+3p expected points, whereas B has (1-p)×2 + p×5 = 2+3p. B is exactly one point worse in every state and every mixture, including p=0 and p=1. Thus A strictly dominates B within this two-action model. A precise probability is unnecessary for this comparison; it would still be needed for many tables whose action rows cross.

First try: correct
