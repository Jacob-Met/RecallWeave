OPEN THE EXPLORER
1. Extract this complete ZIP to any new folder.
2. Open Bloom-filter-explorer.html in a browser. The same HTML may be moved by
   itself to another folder: its controls and lesson download need no siblings,
   server, account, stored state or network request.
3. Read Bloom-filter-explorer-guide.md. Begin with A+B and query X, whose two
   shared bits pass although X is absent from the displayed exact member set.
   Insert X, repeat an insertion, query Y, reset empty and insert Z.
4. Preview removing A or B. The preview operates on a copy; it contrasts unsafe
   bit clearing with rebuilding the remaining exact set and does not mutate the
   live example. The exact member list is teaching information.
5. Compare all 64 ordered query-position pairs for the fixed eight-bit array
   with the separate two-bit random-construction table. Their assumptions
   differ; 9/64 and 5/8 answer different probability questions.
6. Download lesson (.json) saves the unchanged sixteen-question Bloom deck.
   Experiments do not change that deck. Reopening restores A+B; the explorer
   keeps no saved experiments or learner answers.
