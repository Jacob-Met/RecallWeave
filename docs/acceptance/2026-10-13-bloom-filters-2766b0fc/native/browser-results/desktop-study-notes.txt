Explanation: OR preserves existing 1s, but those 1s may be at positions unrelated to where the first mapping queries the second filter’s keys. Matching size alone does not establish a common meaning for each bit. Use compatible mappings and bit numbering for this union operation.

4. A key was inserted into a plain Bloom filter. Which operating condition supports the usual no-false-negatives guarantee for a later query about that represented set?
Concept: membership-evidence
Your first answer: Query with the same mapping after completed insertions, while retaining every bit those insertions set.
First try: correct
Correct answer: Query with the same mapping after completed insertions, while retaining every bit those insertions set.
Explanation: The proof is direct: insertion sets every position the later query will inspect, and those positions remain 1. A changed mapping, erased shared bit or incomplete update breaks that proof. The guarantee is conditional on the filter being maintained correctly.
Apply the idea: Carry the hash configuration and update boundary with a saved filter. Version identity is part of interpreting the bits correctly.

5. With one common mapping, filter F represents only A at (1, 4), and G represents only B at (4, 6), where A and B differ. Their exact sets have empty intersection. A never-inserted key C maps to (4, 4). What does querying C in the bitwise AND of F and G show?
Concept: composition-limits
Your first answer: The AND leaves bit 4 set, so C returns maybe; it is not an exact test of set intersection.
First try: correct
Correct answer: The AND leaves bit 4 set, so C returns maybe; it is not an exact test of set intersection.
Explanation: Both input arrays have bit 4 set, so their AND keeps it. Both query positions for C are 4; the query therefore passes even though C belongs to neither set. This counterexample rules out interpreting AND as exact intersection membership. It does not claim that a compatible AND loses true intersection members.
Apply the idea: When composing approximate summaries, distinguish preserving true members from identifying the exact set. Those are different properties.

6. An 8-bit Bloom filter starts with every bit 0; positions are 0 through 7. Insertion sets both listed positions to 1. Insert A, whose positions are (1, 4), and B, whose positions are (4, 6). Which positions are now 1?
Concept: bit-updates
Your first answer: {1, 4, 6}
First try: correct
Correct answer: {1, 4, 6}
Explanation: Each insertion sets bits; it does not add to a counter or toggle an existing 1. A sets 1 and 4. B leaves 4 set and adds 6, so exactly the three distinct positions {1, 4, 6} are 1.
Apply the idea: When checking a compact index, distinguish a bit that says at least one insertion touched it from a counter that records how many did.

7. A document importer must never discard a genuinely new document as a duplicate. Its plain Bloom filter is correctly maintained for completed entries in an exact document-ID set. What should it do when the filter says maybe present for an incoming ID?
Concept: probability-and-use
Your first answer: Check the exact ID set before classifying it as a duplicate.
First try: correct
Correct answer: Check the exact ID set before classifying it as a duplicate.
Explanation: A nonmember can produce a positive filter result through shared bits. An exact set lookup distinguishes a real duplicate from that false positive. Repeating unchanged queries cannot resolve the ambiguity, and clearing bits can damage other keys’ answers.
Apply the idea: Choose the downstream action according to the cost of an error. Here the filter can avoid some exact checks, while the exact set decides whether an ID already exists.

Concept: composition-limits

First try: correct
Correct answer: Set bits {1, 4, 6}, exactly the array obtained by inserting both A and B into one empty filter.

15. A different experiment starts with two zero bits, positions 0 and 1. Insert one key using two independent uniform hash positions with replacement. Query a distinct, known nonmember whose two positions are also independent uniform draws, independent of the insertion draws. Across the 16 equally likely four-draw outcomes, what is the exact false-positive probability?
Concept: probability-and-use
Your first answer: 9/16, obtained by squaring the average fraction of set bits
First try: needs review
Correct answer: 10/16 = 5/8
Explanation: The four insertion pairs are 00, 01, 10 and 11. Pairs 00 and 11 each leave one bit set, accepting 1 of 4 query pairs. Pairs 01 and 10 fill both bits, accepting all 4 query pairs each. Thus 1 + 4 + 4 + 1 = 10 of the 16 outcomes are false positives. Averaging each state’s query probability differs from squaring the average occupancy.
Apply the idea: For a nonlinear quantity, evaluate it within each possible state before averaging. Replacing a random input by its mean can change the answer.
