      Empty proves absence.

      A never-used empty slot ends the search. A key previously inserted on this path would not have passed it.

      Deleted means keep looking.

      A tombstone holds no key, but preserves a path to keys stored farther along. It can be a later insertion candidate.

      Check before you reuse.

      Insertion remembers the first tombstone, then proves absence. An existing equal key leaves the table unchanged.
