Correct answer: not C -> not (A and B)
Explanation: The contrapositive of P -> Q is not Q -> not P. Here the complete antecedent P is (A and B), so it must be negated as a unit: not C -> not (A and B). 10. The premises A -> B and A are both True. Which listed conclusion must be True?
Concept: Valid inference
Your first answer: not A
First try: needs review
Correct answer: B
Explanation: A is True by the second premise. If B were False, the first premise A -> B would be False, contrary to the given premises. Hence B must be True. This valid inference pattern is called modus ponens; it preserves truth when its premises are true.

First try: correct
Correct answer: A=False, B=True
Explanation: With A=False and B=True, A -> B is True and B is True, yet A is False. This is a counterexample to the argument's validity. The invalid pattern is called affirming the consequent. B might be true in a case where A is false; the original one-way implication does not rule that out.
