    04 · Explain the count

    Every union label gets the same number of first places.

    Let n be the number of union labels and k the number shared by both sets. There are n! complete orders. Fixing any one label in first place leaves (n−1)! orders for the rest.

    First union labelMembershipOrders starting hereMatching minima

    The minima match exactly when that first label is shared. Each of the k shared labels therefore contributes (n−1)! matching orders.

    k × (n−1)! / n! = k / n = |A ∩ B| / |A ∪ B|

    This finite argument explains the ideal permutation model. It does not prove that an arbitrary practical hash function behaves like a uniform random permutation. Empty sets are outside this lab because their minimum label is undefined.
