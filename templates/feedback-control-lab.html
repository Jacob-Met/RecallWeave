Read the rule

Why q predicts the separation

Substitute the correction to get x[n+1] = q x[n] + c, where c = k r + d. Subtract the two runs: their common constant input cancels. In exact arithmetic, a starting difference δ becomes δ qⁿ after n updates.

A fixed point can miss the reference

If q ≠ 1, the fixed point is x* = c / (1 − q). At the default settings it is 2/3, while the reference is 1. A stable recurrence can therefore retain a nonzero reference error. A fixed point exists even when perturbations grow.

The boundary needs its own name

If |q| < 1, deviations decay. If |q| > 1, nonzero deviations grow. At q = −1 they repeat with alternating sign. At q = 1 the separation persists; c = 0 makes every state fixed, while c ≠ 0 causes drift. These boundary cases do not have decaying perturbations.

What this experiment establishes

This is a dimensionless scalar recurrence with constant coefficients, no delay, no saturation and no noise. A finite trace illustrates its behavior; the geometric multiplier supplies the all-update argument. Actual systems and learner outcomes require their own evidence.

Why the last digits can differ

Controls use exact quarter increments, and the computer iterates with ordinary finite-precision numbers. Very small differences can round away when two state values become equal. The table and CSV include both computed separation and the analytical value δ qⁿ.
