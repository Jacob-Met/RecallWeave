            Memoization reuses completed values. A cache hit still enters and returns from a call; it avoids computing that result again. These are call counts, not a timing benchmark.

            What do the counters mean?
            Calls entered
            Every invocation reached through this step, including base cases and cache hits.
            Computed calls
            Calls entered that are not cache hits, including base cases. This does not count arithmetic operations or measure elapsed time.
            Cache hits
            Invocations served by a value already saved during this run.
            Calls returned
            Invocations that have delivered a result and left the stack.
            Active / maximum depth
            Current / largest number of simultaneous frames through this step, including root and base-case calls.

            Factorial has only the zero base case: factorial(0) = 1. Fibonacci uses F(0) = 0 and F(1) = 1, evaluates the left child first, and memoized runs cache every computed result including bases. Inputs are bounded to 0–10; result arithmetic is exact.
