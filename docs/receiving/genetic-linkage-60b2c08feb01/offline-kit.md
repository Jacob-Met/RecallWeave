# Study genetic linkage offline

[Download the lesson kit](genetic-linkage-offline-kit.zip) to explore chromosome phase and then study **Linked genes: same genotype, different gametes**: twelve original questions across four concepts. The kit also includes the separate introductory Mendelian inheritance lesson.

Extract the whole ZIP, preserve its folder layout, and open **START-HERE.html**. Keep `demo.html` beside the `courses/` folder. The labs and learner need JavaScript enabled; no account or installation is required.

1. Open the linkage lab to choose **AB / ab** or **Ab / aB**, enter a whole recombinant-gamete percentage from 0 to 50, and choose **Apply cross**. Editing either input retires the old result.
2. Open the included learner. It starts with its built-in lesson; the kit does not automatically import a course.
3. Use the learner's JSON file chooser to select `courses/genetic-linkage.json`. Check the title, twelve questions and four concepts, then choose **Start this deck**.
4. Complete the lesson, inspect the review, try a separate practice round, and download study notes to retain your first attempts, practice and reflections.

Previewing a course does not replace the current lesson. Explicitly starting it replaces the lesson and its practice context. Use the learner's own save/download controls to keep work you need.

The course JSON is already included. The lab can download the same course again, while **Download this cross (.json)** creates a different observation format. An observation records the applied inputs and probabilities; it is not an importable lesson. Lab inputs reset on reload.

The `courses/` folder also contains the original Mendelian lab, its separate twelve-question JSON and its guide. Choose that JSON explicitly to study segregation, genotype/phenotype and independent assortment first. Markdown guides can be opened in a text editor if the browser does not render them. Their developer maintenance commands refer to the full repository and are unnecessary for this kit.

These are idealized genetic models. Probabilities are not finite-sample quotas, the recombinant-gamete fraction is not a crossover-event count or physical distance, and 50% does not establish chromosome location.

The files work locally; the guides' optional scientific-reference links require a connection. Original course text carries the CC0-1.0 declarations preserved in each JSON. Sources retain their own terms, and the bundle does not relicense application code. `SOURCE-MANIFEST.json` records exact origins and declarations; `SHA256SUMS` detects changed bytes but is not an authenticated signature.
