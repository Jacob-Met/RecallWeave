    Two intervals, one precise answer

    Elements still to resolve

    [lo, hi) includes lo and excludes hi. Everything before lo is already known to be less than the target. Everything at or after hi is already known to be at least the target.

    The next middle index is lo + floor((hi − lo) / 2). A smaller middle value moves lo to mid + 1; otherwise, including equality, hi moves to mid.

    Boundaries that can still be the answer

    [lo, hi] includes both endpoints. Once lo = hi, no unresolved element remains and the single remaining boundary is the answer.

    The result is the first position p where a[p] ≥ target, or n if every value is smaller. Presence is a separate fact: p < n and a[p] = target. An empty array has just boundary 0 and needs zero ordering comparisons.
