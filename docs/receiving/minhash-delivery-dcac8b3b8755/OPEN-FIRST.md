# MinHash companion — open here

Extract this ZIP, then open **preview/index.html** in a modern browser.
That is the exact standalone MinHash page; it requires no server, account,
package installation or network connection. The separately delivered file
is named minhash-explorer.html and has identical bytes.

1. Start with the filled-in sets and select **Compare all permutations**.
2. Compare the exact overlap fraction with the fraction of matching minima.
3. Use Next or the permutation selector to see why one result can differ
   from the full fraction. Expand the complete table when you want every order.
4. Select Five labels, then Compare, to inspect all120 orders and the proof
   that every union label starts the same number of orders.
5. Download an observation to keep the exact applied inputs and every result.

Example buttons load a draft; they do not calculate until you select Compare.
Editing either input retires the previous result. Nothing is saved automatically.
Accepted labels keep exact case and spaces. Both sets must be nonempty, with
at most five distinct labels in their combined union.

## Included material

- preview/index.html: the actual48,370-byte page received in Chrome.
- preview/minhash.md: worked proof, examples, assumptions and source commands.
- preview/probability-foundations.json: the unchanged existing RecallWeave
  probability course; the page also downloads this exact file.
- source/: all nine exact files needed to inspect, test and rebuild this
  companion. From that directory run node tools/build-minhash.mjs --check,
  or node --test tests/minhash.test.mjs. Node is needed only for development.
- evidence/: original mathematical oracle, author build/test records, the
  single independent browser course, actual downloads and four screenshots.
  evidence/README.md explains the separate courses and their practical limits.
- MANIFEST.json: the byte length, SHA-256 and Git blob identity of every other
  ZIP member. It identifies content; it is not a provenance signature.

To study the downloaded course, use your existing RecallWeave learner:
Bring your own lesson → Preview → Start this deck. The learner is not bundled
or changed here. A MinHash observation is a mathematical record, not a lesson
or answer archive.
