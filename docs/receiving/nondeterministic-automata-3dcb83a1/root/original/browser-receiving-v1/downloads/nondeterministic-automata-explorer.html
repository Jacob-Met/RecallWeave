Branching paths.
One exact set at a time.

Edit a small nondeterministic machine, follow its possible states, and construct the deterministic machine that keeps the same possibilities together.

This lab runs offline. No account, upload, random path choice or probability is involved. Alphabet: 0 and 1; 1–5 states; words up to 24 symbols.

1. Build the machine

Loading or replacing a table discards its current edits. Choosing a size alone does not change the current -state table.

Enter destination indices separated by commas, for example 0,2. Leave a cell blank for no destinations (∅). ε edges consume no symbol. An accepting flag decides whether a path may finish successfully at that state.

StateAccepts?On 0On 1On ε

Use only 0 and 1. Leave blank for the empty word, ε. Do not type the ε glyph or spaces.

2. Follow every possibility

The active set starts with ε-closure of the start state. For each symbol, collect all symbol destinations, then follow every ε edge reachable from them. The last column is acceptance at that prefix; the whole word uses only the final row.

3. Keep each reachable set as one DFA state

Each row is a set of original states, not a single chosen path. It accepts if any member accepts. The table explores all reachable subsets in breadth-first order, trying 0 before 1; a first word records how each subset was reached.

This construction preserves the language because each DFA state is the NFA's exact closed active set after the same prefix. It does not minimize the number of states. The trace length limit does not truncate this reachable transition graph.

What this lab establishes

It computes exact finite sets and transitions for the admitted machine. It does not select random paths, parse regular expressions, minimize DFAs or estimate the chance of acceptance. It does not measure learning outcomes. Edits remain only in this tab; reload returns to the initial example.
