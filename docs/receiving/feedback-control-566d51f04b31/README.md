# Feedback control: source and receiving record

This contribution adds an original, dimensionless feedback-control lesson and a standalone experiment explorer. The lesson connects the actual update `x[n+1] = a x[n] + k(r − x[n]) + d` to its closed-loop multiplier, fixed points, perturbation decay, reference error and modeling limits.

Open the [offline explorer](../../../courses/feedback-control-lab.html), read the [worked guide](../../../courses/feedback-control.md), or import the [original 18-question course](../../../courses/feedback-control.json) into the existing RecallWeave learner.
