# Boolean logic course and offline explorer: receiving record

This contribution adds an original twelve-question Boolean logic course and a separate, self-contained truth-table explorer. A learner can compare expressions, inspect every assignment and a counterexample, download the full CSV, and download the exact lesson JSON for the existing RecallWeave learner. It changes no existing learner, importer, model, authoring, notebook, trace, or other course implementation.

The work was claimed in [RecallWeave #59](https://github.com/Jacob-Met/RecallWeave/issues/59) and the [estate coordination record](https://github.com/Jacob-Met/hamon/issues/140#issuecomment-6061872615). Other active course and learner scopes retain their implementation ownership.

## Replay

From a complete published repository checkout:

```bash
node tools/build-boolean-logic.mjs --check
node --test tests/boolean-logic.test.mjs tests/boolean-logic-course.test.mjs tests/boolean-logic-build.test.mjs
node tools/check-boolean-logic-browser.mjs --browser /path/to/chromium --output /tmp/recallweave-boolean-receiving
```

The optional browser driver needs Node 22 or newer and an existing Chrome/Chromium executable. Give each replay a fresh output directory and a short writable temporary directory. No package installation or provider access is needed.

The frozen independent export receiver can replay the recorded current packet without opening a browser:

```bash
node docs/receiving/boolean-logic-acd057031fb2/independent-export/receive-export-bytes.mjs \
  --packet docs/receiving/boolean-logic-acd057031fb2/current-browser \
  --output /tmp/recallweave-boolean-independent-exports \
  --expected-demo-sha c7f1877facf1c62c741373b6bd03b645ec351af3457da06c45988efde805701a \
  --expected-receipt-sha 72f0beacb8f61e4339138eca75a1a30e286858d03550abd67bb0a49737af9e2c
```

The three negative controls intentionally run after immutable input admission. They preserve aggregate scores or item sets and must fail per-item identity checks, so a simple file-hash mismatch cannot produce the claimed rejection.

## Limits of the contribution

The explorer evaluates the explicitly bounded classical grammar described in the [course guide](../../../courses/boolean-logic.md). It does not establish the truth of real-world premises, causation, or learning efficacy. The course is original material with item explanations, transfer prompts, permission and AI-assistance disclosure. No other subject course or ongoing learner session is modified.
