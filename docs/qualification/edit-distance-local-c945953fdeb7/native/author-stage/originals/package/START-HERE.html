Explore edit distance.
Then learn the reasoning.

Extract the whole ZIP into one folder and keep its courses folder beside demo.html. Open this START-HERE file in your browser. No installation, account, server or internet connection is required for the included activities.

  1. Open the edit-distance explorer. Load an example or enter your own two short strings and operation costs, then choose Compute minimum cost. Inspect a prefix cell, the tied choices and one alignment. Use Previous step and Next step to replay it. Changing inputs retires the old result until you compute again.
  2. Open the unchanged RecallWeave learner. It initially shows its bundled biology lesson. Under Bring your own lesson, use Choose a deck file to select courses/edit-distance.json from this extracted folder. Preview it, then choose Start this deck. Starting replaces the current lesson in that tab. Nothing is uploaded.
  3. Answer the twelve questions. Read the explanations and your original review; practice missed items separately. A correct practice retry does not rewrite the first answer. Use the learner's existing explicit downloads if you want to keep a record before closing or refreshing.

The explorer's Download lesson saves this same authored course for the existing learner import flow. Download experiment saves the current valid table/alignment record; it is not a learner lesson or restore file. Download worked guide saves the included guide.

The stated model matters. Inputs contain 0–16 literal Unicode scalars. Costs are positive integers 1–9. This model does not normalize text, ignore case or allow a one-step transposition. It displays one optimum, not a uniqueness proof. The lesson illustrates reasoning; no learning-outcome claim is made.
