        Experiment B · A separate two-bit filter

        Now randomize construction.

        Use just two bits, one inserted key and two hash positions per key. Draw the two insertion positions and two nonmember query positions independently and uniformly from {0, 1}. Each of the 16 four-draw outcomes is equally likely.

        Four insertion outcomes, each with four equally likely query pairs
        Insertion pairSet bitsQueries accepted

        The acceptance counts are 1 + 4 + 4 + 1 = 10. The middle insertion outcomes fill both bits, so all four query pairs pass.

        Square before you average. The mean fraction of set bits is 3/4, but (3/4)² = 9/16 differs from the exact 10/16. Average each constructed array’s acceptance probability; squaring its mean occupancy loses the variation.

        This finite experiment does not use or change the eight-bit set above. It is not a measured false-positive rate of a deployed filter.
