# Bloom shared-bit explorer — source and native receiving

This contribution makes the original Bloom lesson explorable in one local HTML
page. Insert the seven declared toy keys, inspect their shared bit positions,
query exact membership versus filter evidence, and preview why clearing a
shared bit can lose a remaining member. The deletion preview operates on copies.
The live state uses insertion and whole-example reset only.

The fixed-state table enumerates all 64 ordered query-position pairs for the
current eight-bit array. A separate two-bit construction table explains the
1, 4, 4, 1 accepted-query counts and exact 10/16 result. The seven named keys
are fixed examples, not the random query population. The embedded download is
the unchanged sixteen-question lesson.
