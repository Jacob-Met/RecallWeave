## The contribution

The authored counts define a uniform draw from a finite box of cards with two labels. The lab accepts 2–4 rows and columns, integer counts 0–999, and a positive total. Its ten examples distinguish independence, deterministic and biased copies, opposite labels, grouping, noisy association, a rare uncertainty-increasing observation, unused categories, a constant pair and very small dependence.

The model returns a detached, frozen snapshot containing every joint and marginal fraction, both conditional directions, entropy contributions, signed information terms and exact integer factorization comparisons. Zero-marginal conditional distributions remain undefined. Zero-probability weighted terms are zero without assigning finite zero surprise or pointwise information to impossible outcomes.

Independence is decided by n*N == rowTotal*columnTotal for every cell. The approximate information total uses an algebraically equivalent divergence expression that avoids cancellation near independence. The signed contribution table still shows the original p*log2(p/q) terms, including negative terms.

Editing a draft retires the previous applied result and observation download. Changing dimensions resets the conditioning selection. User-requested observation downloads include the complete applied analysis and selected observation; the fixed lesson and guide do not change with the editable table. There are no network requests, browser-storage operations or automatic downloads.
