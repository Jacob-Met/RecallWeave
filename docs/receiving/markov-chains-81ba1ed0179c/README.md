## Meaning and limits

The page calculates distributions for hypothetical finite time-homogeneous chains. It does not simulate sample paths, prescribe realized counts, forecast a real system or validate learning efficacy. Integer-percent inputs are explicit and never silently normalized. The finite thirty-transition horizon and rounded labels are not proofs of convergence.

Original course content is CC0-1.0; referenced materials retain their own terms. No third-party exercises, passages or figures are copied. This packet qualifies native source and its receiving; it does not claim a deployed public service or automatic catalog inclusion.
