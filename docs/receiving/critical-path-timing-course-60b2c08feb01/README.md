# Critical-path timing course: qualified local work and preserved evidence

This packet is intended for isolated **non-main branch custody without a pull
request**. It is not integration into main, installed adoption, a deployment or
an educational-efficacy claim. The repository's required integration gates and
protections remain required. GitHub Actions are prohibited under the current
hold, including dispatches, reruns and writes that would trigger a workflow.
Equivalent native gates may follow the established owner process without
bypassing protections; this packet does not grant an exception or waive a gate.

The scope is [RecallWeave issue 171](https://github.com/Jacob-Met/RecallWeave/issues/171):
three new course files plus one root-authored additive repository README section.
The existing learner, importer, graph/timing models, catalog and all workflows
remain unchanged. Read [qualification.json](qualification.json) for exact source
identities, evidence pins and the distinction between current and historical
results. [readme-receiving.json](readme-receiving.json) verifies that removing the
1,073-byte README insertion restores the complete original file.
