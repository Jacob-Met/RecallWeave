The rule

Look first. Then take a record.

Reject the first skip arrivals. Then select the first arrival better than everything seen before. If nothing was selected earlier, take the last arrival.

A record means best so far. It need not be best overall. Rejected arrivals cannot be recalled.

The boundary

One order is not a probability.

Rank n is best. The complete order is visible for teaching; the rule sees only the observed prefix. The probability table separately weights all n! orders equally.

Known n, distinct ranks, no recall. No random sampling or real-world recommendation.

    Why the count works

    Fix the best item's position.

    For a positive skip r, suppose the best arrives at position j. It wins only when the best of its j−1 predecessors was among the first r arrivals.

    That accounts for r × (n−1)! / (j−1) orders. Add these counts for j=r+1 through n, then divide by n!.

    With skip 0, choose the first arrival: exactly (n−1)! wins. With skip n−1, choose the last: chance 1/n. At n=1, that is certainty.

    The mandatory fallback changes what gets selected when no record arrives; it cannot make a nonrecord into the global best.
