1. State the conjecture

Let S(n) add the terms t(k) = ak + b from k = 1 through n. Is S(n) always equal to Q(n) = (An² + Bn + C)/D on the stated integer domain?

Use whole numbers −20 through 20 for a, b, A, B and C. D must be 1 through 20. Spaces, decimal points and exponent notation are refused. The first integer is 0 or 1; the sum still starts at k = 1.

2. Check the base

The actual base is computed from the terms. An empty sum has value 0, with no extra k = 0 term.

3. Derive the successor

For an arbitrary allowed n, assume S(n) = Q(n). Then S(n + 1) = Q(n) + t(n + 1). We must show that this equals Q(n + 1).

4. Check the identity for every n

This lab checks only arithmetic sequences and quadratic rational conjectures. It supplies the displayed algebra for that family; it does not decide arbitrary mathematical statements.
