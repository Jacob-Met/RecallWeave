Which question are you answering?

These recorded attempts? The pooled fraction describes each option's actual sample. A chosen common group mix? Use the stated reference weights. Neither question makes the other arithmetic wrong.

What would changing the option cause? The table alone does not answer that. Assignment, common causes, and when groups were measured matter. Grouping by a consequence of the option can change the effect being studied.

No confidence intervals, significance tests or causal effects are estimated. Rates are displayed to two decimal places; exact comparisons can remain different even when the displayed percentages match.
