The checked course also works with the project's exact current Deck Studio and learner at parent `d8a9ff81e8e5290e8daad5b4af957d4eddc0ee74`, including review, missed-question practice, study notes and restoration of a saved learning trace.

The initial learner page opens its bundled lesson. Select the checked shortest-paths JSON under **Bring your own lesson**, inspect its preview, then choose **Start this deck**. The [worked guide](../../../courses/shortest-paths.md) gives the complete import, edit, save and restore order. ## Use, reproduction and limits

Opening the explorer, Studio or learner needs no installation, server, account or network connection. Browser state is not saved automatically. The checked course remains fixed when graph weights are edited; the graph trace describes only the run at its download time. Saved learner traces require the exact same loaded checked course and model.

The mathematical explanations are original and link to their primary algorithm references. The model and feedback are learning aids, not validated measurements of ability or evidence of learning gains. Browser evidence covers the recorded Chromium 153/macOS configuration and finite viewport/keyboard histories; it is not a cross-browser matrix or accessibility certification.

For source checks, use:

```sh
node tools/make_shortest_paths_explorer.mjs --check
node --test tests/shortest-paths.test.mjs
```

The optional browser driver accepts an installed browser and an empty output directory. The independent current-consumer driver, exact inputs, logs, snapshots, downloads and negative evidence are retained in the separate receiver packet. No modified private learner or competing importer was used.
