When do separate pieces become one?

Add a connection, follow a representative, and watch a collection of islands become a connected whole. Compare the graph you describe with the parent tree that remembers its groups.

1. Describe the connections

Each element starts alone. Connections are undirected.

Use join A B to add a connection or find A to inspect a representative. Use uppercase element letters and at most 32 commands. Blank lines are ignored.

Predict before you step

In Connect three islands, stop just before find D. How many components remain? Will finding D connect anything new?

The rules in this lab

  • A join finds both roots, then attaches the smaller component to the larger.
  • If sizes match, the earlier root letter wins. Reversing the command does not reverse this tie rule.
  • Compression makes the nodes visited by a find point directly to its root.
  • A find and a repeated connection can change parent pointers without changing the groups.

Editing an input clears the accepted trace and its download. Apply again when the whole sequence is ready. No commands change files, accounts, or an open learner session.

This model supports adding connections. It does not remove an old graph edge or infer that every join forms a new cycle.
