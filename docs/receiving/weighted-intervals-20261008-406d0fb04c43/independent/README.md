## Independent mathematics

`receive-math.mjs` was frozen before any candidate inspection, SHA256 `2069431d19acb3ed72f58709a3aa198e4c97f6afc1e39c30e597f9c4a187fc26`. It computes an optimum by enumerating every subset, checking every selected pair for half-open interval compatibility, and comparing total values. It does not use the candidate's dynamic recurrence to compute the reference optimum.

Among equal-valued feasible subsets it selects the smallest bitmask in finish/start/code-unit-ID order. The latest ordered activity has the highest bit, so this independently expresses the declared skip-current tie rule. Each prefix is enumerated independently. The receiver then checks ordered inputs, every table field, predecessor indices, selected IDs, all backtracking jumps, and the separate earliest-finish comparison.

**8,265 valid cases and 42 refusal cases passed.** The valid cases comprise nine named examples/boundaries, all 4^6 combinations in which each of the six nonempty intervals with endpoints 0–3 is absent or has value 0, 1 or 2, both original and reversed input orders, and 64 deterministic eight-activity cases. Controls include empty/all-zero schedules, touching endpoints, maximal values/times, nested intervals, equal finishes, ID ordering, and alternatives with equal optimal value. Frozen input arrays/objects remain unchanged and returned activity objects are detached.

The refusal matrix covers malformed top-level/row values, excess activities, duplicate or invalid IDs, absent fields, nonnumeric/noninteger/nonfinite values, bounds and nonpositive durations. The assertion is refusal, not a prescribed error class or wording. This is finite qualification of the stated domain, not exhaustive enumeration of every possible admitted eight-activity input.
