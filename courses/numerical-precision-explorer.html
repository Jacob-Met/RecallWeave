A short decimal label can hide a longer stored value. This lab follows one addition or subtraction through input conversion and arithmetic, using exact fractions to keep the comparison visible.

Compare two values

Plain decimal text: up to 18 whole and 18 fractional digits, with an optional + or - sign. Write 0.5, not .5. Exponents, commas and expressions are refused.

Try a different case

Three values. Two possible changes.

  1. Decimal reference: the exact arithmetic implied by your written values.
  2. After conversion: exact arithmetic on the Number values that were actually stored.
  3. Stored result: the value after JavaScript performs the operation.

The signed changes between these steps add up exactly. They can reinforce each other or cancel.

Your decimal text is a mathematical reference. The lab does not assign measurement accuracy to it.
