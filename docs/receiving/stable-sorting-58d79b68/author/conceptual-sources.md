# Conceptual sources

All teaching prompts, examples, explanations, transfer cues, UI and implementation are original. Primary conceptual checks used Robert Sedgewick and Kevin Wayne's Princeton Algorithms materials:

- https://algs4.cs.princeton.edu/21elementary/ — record sorting and elementary recipe context.
- https://algs4.cs.princeton.edu/code/javadoc/edu/princeton/cs/algs4/Insertion.html — insertion stability and adjacent exchanges/inversions.
- https://algs4.cs.princeton.edu/code/javadoc/edu/princeton/cs/algs4/Selection.html — selection's lack of general stability.
- https://algs4.cs.princeton.edu/25applications/ — equal-key stability and successive key sorts.

Direct opens of three initial Princeton pages returned403 during research. A stronger primary-domain search recovered the official Javadoc and sorting-application material; the access errors are not treated as dead-link evidence. No reference code, prose passages or figures were copied. Princeton's implementation counts self-exchanges; the authored recipe explicitly omits them. Operation counts are facts about the declared recipes and are not timing or learning-efficacy claims.
