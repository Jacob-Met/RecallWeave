4. Profile P has 27 complete strict ballots: 11 rank A > B > C; 9 rank C > B > A; 5 rank B > C > A; 2 rank B > A > C. Exactly 16 ballots rank B above A, and 18 rank B above C. Why is B’s 2, 1, 0 Borda score equal to 16 + 18 = 34?
Concept: borda-scores
Your first answer: On each complete ballot, B’s Borda points equal the number of other alternatives below B.
First try: correct
Correct answer: On each complete ballot, B’s Borda points equal the number of other alternatives below B.
Explanation: If B is first, two alternatives are below it and it earns 2; second gives one and 1; third gives none and 0. Summing that count by ballot equals summing, for each opponent, the ballots that put B above that opponent. The identity holds for every alternative, whether it wins or loses its pairwise comparisons.
Apply the idea: Verify the same identity for A using 11 ballots above B and 13 above C. Then check C using 14 above A and 9 above B.

8. Profile Q has 9 complete strict ballots: 4 rank A > B > C; 3 rank B > C > A; 2 rank C > A > B. The head-to-head winners are A over B, B over C and C over A. In a sequential procedure, the winner of the first comparison meets the remaining alternative. Which pair of outcomes is correct?
Concept: pairwise-majorities
Your first answer: A versus B first leads to C; A versus C first leads to B.
First try: correct
Correct answer: A versus B first leads to C; A versus C first leads to B.
Explanation: A beats B first, then C beats A, so the first order leaves C. C beats A first, then B beats C, so the second leaves B. These calculations use the same fixed rankings; only the specified comparison order changes. A sequential winner need not defeat every alternative.

9. Profile Q has 9 complete strict ballots: 4 rank A > B > C; 3 rank B > C > A; 2 rank C > A > B. Its pairwise majorities are A over B, B over C and C over A. What follows?
Concept: pairwise-majorities
Your first answer: No alternative defeats both opponents, although every individual ballot is a consistent strict ranking.
First try: correct
Correct answer: No alternative defeats both opponents, although every individual ballot is a consistent strict ranking.
Explanation: A loses to C, B loses to A, and C loses to B, so none is a Condorcet winner. The ballots themselves are linear orders. Combining different supporting majorities does not preserve transitivity: the group supporting A over B is not required to be the same group supporting B over C.
Apply the idea: Name the supporting groups for each majority. Explain why the existence of a cycle in this example makes no claim about how frequent cycles are in actual elections.
