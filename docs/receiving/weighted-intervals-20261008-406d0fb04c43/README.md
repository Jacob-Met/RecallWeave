# Weighted interval scheduling receiving

This contribution adds an original twelve-question lesson and a self-contained offline explorer to RecallWeave. The learner can edit fixed-time activities, inspect prefix take/skip decisions, reconstruct one compatible optimum, compare earliest finish, and download the exact course or a worked trace.

The [course guide](../../../courses/weighted-interval-scheduling.md) contains the complete six-row example, all answer derivations, problem boundaries and maintenance commands.
