Why zeros and ones are enough

If an ordered input leaves a larger value before a smaller one, a threshold between them maps that inversion to 1 before 0. Applying the same nondecreasing threshold map before or after any min/max comparator gives the same result. A fixed network that sorts every binary input therefore cannot leave such an inversion.
