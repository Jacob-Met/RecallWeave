RecallWeave offline course pack

1. Extract the entire ZIP. Keep the RecallWeave folder together.
2. Open catalog.html in a web browser with JavaScript enabled.
3. Choose Open learner to open the sibling demo.html.
4. Under Bring your own lesson, choose a JSON file from the courses folder
   (or a course file downloaded from the catalog).
5. Inspect the preview, then select Start this deck.

Opening and previewing a file leaves the current lesson in place. Start this deck
begins a fresh session. The catalog and learner need no server, account or network.
Optional links to other tools or the public download page may need a connection
or a separate download.

Course files keep their original source and permission statements. Learning-model
estimates are illustrative, not grades or evidence of learning efficacy.
Use the learner's explicit download controls to keep a study record; reloading
clears the tab's in-memory session.

SHA256SUMS.json lists the byte length and SHA-256 hash of every other file in this
pack. It describes file integrity, not authorship or an authenticated signature.
