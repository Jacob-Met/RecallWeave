Why the two combinations?

Exactly k marked tokens needs a choice of k from K, and a choice of n−k from N−K. Multiplying those counts identifies complete subsets:

P(X=k) = C(K,k) C(N−K,n−k) / C(N,n)

Possible counts run from max(0,n−(N−K)) through min(n,K). An event adds disjoint count rows. Equal inclusion chances for individual tokens alone do not guarantee this uniform-subset model.

Assumptions, exact arithmetic and sources

Tokens are distinct; categories are fixed; every subset of size n is equally likely. No random samples, measured data or estimates are generated. A compatible subset is a deterministic illustration. Inputs are bounded to N≤200 for this teaching interface.

BigInt combination counts and reduced rational strings preserve the exact results. Decimal fields in the observation and bars are floating-point approximations. The expected count is nK/N. For N>1, variance is n(K/N)(1−K/N)(N−n)/(N−1); the one-token case is deterministic and handled directly. An empty sample has one possible subset.
